# Подрядчики — Краков

**Дата обновления:** 2026-04-26  
**Фокус:** Фирмы с правом на применение **НДС 8%** (материал + монтаж).

---

## Требования к подрядчику

1. Активный плательщик НДС (VAT-owiec) — проверить на **Biała Lista**
2. Выставляет одну фактуру с НДС **8%** (материал + работа)
3. Имеет партнёрские скидки в салонах (Max-Fliz, Bokaro, Hoff)
4. Предоставляет детализированную смету (Kosztorys) с разделением NETTO
5. Работает по этапной оплате (без 100% предоплаты за работу)

## Как проверить фирму перед оплатой

1. **Biała Lista podatników VAT:** [podatki.gov.pl/wykaz-podatnikow-vat](https://www.podatki.gov.pl/wykaz-podatnikow-vat/)  
   → Ввести NIP фирмы → убедиться, что статус «czynny» (активный)
2. **KRS / CEIDG:** Проверить дату регистрации, не ли ликвидации
3. Не платить наличными — только **банковский перевод (Przelew)**
