# Исследование: Centrum Meble (Meble.pl)

## Цель
Оценка возможности заказа премиальной кухни с использованием системы "2-в-1" (Tip-On Blumotion) и фасадов Cleaf через онлайн-платформу [centrum.meble.pl](https://centrum.meble.pl).

## Ключевые возможности конструктора
Страница модуля: [Szafka dolna z 2 szufladami](https://centrum.meble.pl/meble-na-wymiar/szafki-kuchenne/szafka-dolna-z-2-szufladami.html)

### 1. Выбор материалов (Фасады Cleaf)
*   Выбор осуществляется прямо в блоке **"Front"**.
*   При клике на текущий декор открывается модальное окно.
*   **Путь**: `Płyty TSS Cleaf` -> выбор конкретного декора.
*   **Рекомендуемые темные декоры**:
    *   `Cleaf LR29 Fittipaldi` (черный сланец)
    *   `Cleaf S013 Old Jack` (темное дерево)

### 2. Фурнитура "2-в-1" (Blum Tip-On Blumotion)
*   **Опция в конфигураторе**: *"Otwieranie naciskiem (Tip-On + Hamulec Blumotion)"*.
*   **Суть**: Сочетает открытие нажатием (Push-to-open) и мягкое закрытие (Soft-close).
*   **Важно**: Система автоматически подбирает нужные направляющие (Tandembox Antaro/Legrabox) и присадки.

### 3. Работа с файлами (Advanced)
*   Сайт поддерживает **подстановку файлов** для нестандартных заказов.
*   **Сервис "Przesyłanie plików"**: [centrum.meble.pl/uslugi/przesylanie-plikow/](https://centrum.meble.pl/uslugi/przesylanie-plikow/)
*   **Формат**: `.COR` (Corpus). Это позволяет технологу подготовить проект в профессиональном ПО и загрузить его для мгновенного расчета и производства.

## Технический workflow
1.  **Набор модулей**: Выбираем стандартные шкафы через конструктор, задавая размеры с точностью до 1 мм.
2.  **Кастомизация**: Для каждого модуля выбираем "Tip-On Blumotion" и фасады Cleaf.
3.  **Загрузка (опционально)**: Если есть уникальные элементы, используем "Przesyłanie plików" для отправки чертежей из Corpus.
4.  **Сборка**: К каждому заказу прилагается персональная PDF-инструкция (пример: [szafka003-D2S.pdf](https://s1.meble.pl//gfx/przykladowe_instrukcje/D2S/szafka003-D2S.pdf)).

## Вывод
Платформа идеально подходит для "разделенной" стратегии: мы сами (или с технологом) конфигурируем премиальные материалы и фурнитуру, а фабрика берет на себя ЧПУ-обработку и логистику.
